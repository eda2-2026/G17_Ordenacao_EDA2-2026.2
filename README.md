# G17_Ordenacao_EDA2-2026.2

## Passo a passo da instalação em Ambiente Linux

### Clone o repositório e entre no diretório
```bash
git clone https://github.com/eda2-2026/G17_Ordenacao_EDA2-2026.2.git &&
cd G17_Ordenacao_EDA2-2026.2
```
### Adicione permissão de execução (caso ainda não esteja)

```bash
chmod +x build.sh run.sh
```
### Execute o script `build.sh`

```bash
./build.sh
```

### Execute o programa

```bash
./run.sh
```
## Passo a passo da instalação em Ambiente Windows

### Clone o repositório (opcional)

```bash
git clone https://github.com/eda2-2026/G17_Ordenacao_EDA2-2026.2.git
```

### Abra o repositório do GitHub e simplesmente baixe o Raw File "ProjetoEDA.exe"

### Execute o arquivo 

**Pode ser que ao executar o arquivo, apareça um aviso de segurança do windows impedindo a instalação, basta apenas executar mesmo assim**

# Avisos Importantes

**Como os números são sorteados aleatoriamente, a base de dados pode ficar bem heterogênea com números muito grandes e muito pequenos, então dependendo do algoritmo que você selecionar para a simulação, ele pode demorar bastante.**
